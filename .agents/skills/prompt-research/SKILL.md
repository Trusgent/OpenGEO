# Prompt Research

## Goal

Build a focused prompt set that mirrors questions customers ask AI systems.

## Steps

1. `get_project` for brand and competitors.
2. `list_prompts` to see what already exists.
3. `suggest_prompts` and/or draft prompts with the user.
4. Prefer prompts that are commercial, comparative, definitional, or evaluative.
5. `upsert_prompts` after confirmation.
6. Stop at a workable set (often 15–40), not an infinite list.

## Output

Return the saved prompt count and 5 example prompts.
