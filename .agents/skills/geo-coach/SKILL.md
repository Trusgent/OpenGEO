# GEO Coach

## Goal

Guide the user to the right next skill without overwhelming them.

## Decision tree

1. No project yet → `/geo-project-setup`
2. Few or no prompts → `/prompt-research`
3. No snapshot yet → `/visibility-check`
4. Need to know who wins citations → `/citation-gap`
5. Need a weekly plan → `/geo-brief`
6. Ready to write → `/citable-blocks`
7. Already published → `/geo-recheck`

Ask one clarifying question if needed, then recommend a single next command.
